ATM Rekon App

Rekonsiliasi log transaksi ATM, counter mesin, dan opname fisik kas. Mesin: Wincor PC280 CDM-V4. Data diproses di browser Anda dan tidak dikirim ke mana pun.

1. Upload log jurnal

Seret file .jrn / .txt ke sini, atau
Bisa beberapa file sekaligus. Setiap file dianggap satu hari.

2. Ringkasan per hari

3. Opname fisik

Kaset 1
Kaset 2
Atau total fisik (sisa + reject), jika hanya punya total

4. Hasil rekonsiliasi

Segmen periode (clear / add cash)

5. Counter dan log SOP per file

6. Detail transaksi

Format log yang dibaca: baris CASH REQUEST, CASH n:c,k;, CASH PRESENTED, CASH TAKEN, blok tabel TYPE 1 TYPE 2 (CASSETTE / +REJECTED / +DISPENSED / =TOTAL), dan blok CASH COUNTERS BEFORE/AFTER SOP.
